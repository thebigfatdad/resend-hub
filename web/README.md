# web — Phase 3 stub

React + Vite + TypeScript + Tailwind UI on Firebase Hosting.

This directory is a **thin HTTP client only**. All business logic lives in `/api`.

## Status
Phase 3 — not yet implemented.

## Planned screens

- Thread view (conversation + customer panel + reply box)
- Quick actions (escalate, assign, snooze, close)
- KB tab (articles + gap-approval inbox)
- Brand settings (senders, voice profile, policy toggles)

## Setup (Phase 3)
```bash
npm create vite@latest . -- --template react-ts
npm install
npm run dev
```
